# LiSync : Jam with your friends on echo.



### Breakdown of the extension :


Category : tracker

LiSync tracks the songs you play, when you host a jam, it sends the URI (if remote doesn't use the same extension source as you it will send ids to search on your current extension and autoplay)

### Actual dev status :


Jam rooms are working, IDs are sent and received but echo is not starting to play.

In work : AutoPlayer (track launcher)
